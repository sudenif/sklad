# Учёт комплектующих

Локальное Android-приложение версии 1.1.0 для учёта покупок, продаж, расходов и комплектующих. На телефоне работает без интернета. Требуется Android 8.0 или новее.Добавлены фото, разборка купленого лота по частям, обращение внимание на залежавшееся железо

## Запуск в Android Studio

1. Открой папку `app-source` как проект.
2. Для сборки нужны JDK 17, Android SDK Platform 35 и Build Tools 35.0.0. Дождись синхронизации Gradle. При первой сборке Gradle скачает зависимости, если их ещё нет в кэше.
3. Выбери эмулятор или подключённое устройство и нажми **Run** для модуля `app`.

## Сборка из терминала

Укажи пути к JDK и Android SDK в переменных `JAVA_HOME` и `ANDROID_HOME`. Запусти сборку в PowerShell из папки проекта.

```powershell
.\gradlew.bat assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`. В Linux и macOS используй `./gradlew assembleDebug`.

Если на телефоне уже установлена подписанная версия, проверяй отладочную сборку на эмуляторе. Для обновления с сохранением записей нужен APK с тем же ключом подписи. Готовый подписанный APK для установки лежит в соседней папке `extras/dist`.

Записи и фотографии хранятся на телефоне. Резервную копию можно сохранить через значок копий на «Обзоре».
